## 四、現行付款與入帳流程

1. 先確認商品、適用帳戶與版別；需要儲值時，選擇固定面額並建立儲值單。
2. 依儲值單與客服確認的正式收款資訊付款，付款金額與期限應以該筆交易明細為準。資訊不明或已逾期，請先重新確認。
3. 提交該筆儲值單需要的付款核對資訊，保留訂單及付款紀錄。
4. **由管理員核對實際收款後發點**。提交付款截圖、取號或顯示待處理，均不等於已付款確認或星點已入帳。
5. 星點入帳後，在商店確認商品、折扣與實際扣點，再依確認結果購買。

**線上付款與自動儲值仍在準備中，尚未開放使用。** 正式開放時間、付款方式與適用規則將另行公告；目前不要將測試畫面視為已開通的收款服務。

本 GitHub 頁面不收集信用卡資料，也不以公開留言受理付款資訊。需要實際付款時，請先核對正式交易資訊，不要將銀行密碼、簡訊驗證碼或完整卡片資料交給交易對象。
