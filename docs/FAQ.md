# 星瞳腳本：常見問題

## 首次安裝和更新包有什麼不同？

首次安裝需要完整程式基底。`update_patch.zip` 是一般版拆分更新包，`update_lite_patch.zip` 是 VM Lite 專用更新包，兩者不可混用。

## 為什麼更新包比完整程式小？

拆分更新包只包含相對於指定完整基底需要替換或新增的檔案；請依每個 Release 的基底版本說明操作。

## 更新後設定會被覆蓋嗎？

正式更新流程會排除使用者設定、角色 profiles、授權資訊及執行紀錄。更新前仍建議保留自己的設定備份。

## 如何回報辨識或流程問題？

請附上版本、選擇的遊戲、解析度、問題發生時間與已移除敏感資訊的日誌片段。不要公開授權碼、Webhook、API Key 或個人設定檔。

## 在哪裡下載正式版本？

請以 `ayzn0524/MStarBot_Updates` 的 GitHub Releases 為準，其他來源由產品頁另行公告。
