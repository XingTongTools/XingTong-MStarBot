# 星瞳 MStarBot：常見問題

[返回產品介紹](../README.md)

## 星瞳是什麼產品？

星瞳是由個人工作室維護的 Windows 遊戲自動化軟體，支援楓星、新楓之谷：經典版，包含視覺辨識與可設定的遊戲流程。這是星瞳自己的產品頁，不是遊戲營運商官方頁面，也不代表遊戲營運商授權或背書。

## 哪裡查詢價格與授權方案？

完整公開售價及授權方案尚未在本頁公告。購買前請透過[星瞳產品客服 LINE](https://lin.ee/OC4MoWM)確認商品版本、金額、授權期間、裝置限制、交付與啟用方式，以及售後及退款條件。

請先取得明確方案再付款。下載程式或更新檔，不等同於已完成購買或取得所有功能的使用授權。

## 現在可以用 PAYUNi 付款並自動收到星點嗎？

目前尚未正式啟用。測試畫面及開發驗證不表示已開放正式收款或線上自動儲值，請以正式公告及客服說明為準。

若實際方案採先儲值星點再購買商品或授權，請於付款前確認星點的用途、兌換方式、有效期限、轉讓限制及退款規則。

## 首次安裝和更新包有什麼不同？

首次安裝需要完整程式基底。`update_patch.zip` 是標準版（一般版）拆分更新包，`update_lite_patch.zip` 是 VM Lite 專用更新包，兩者不可混用。

若 Release 僅附更新包，或沒有標明完整基底與對應版本，請先向產品客服確認完整安裝來源。不要把拆分更新包當作首次安裝程式。

## 為什麼更新包比完整程式小？

拆分更新包只包含相對於指定完整基底需要替換或新增的檔案；請依每個 Release 的基底版本與版別說明操作。

## 標準版和 VM Lite 可以互相套用更新嗎？

兩種版本的程式基底與更新包不可混用。請依目前安裝的版本及該次 Release 說明，選用 `update_patch.zip` 或 `update_lite_patch.zip`。不確定版別時，請先詢問客服。

## 需要什麼系統環境？

本產品為 Windows 桌面軟體，目前更新版需要 WebView2 Runtime。其餘硬體、遊戲版本與解析度需求，請在安裝或購買前依版本說明及客服確認。

## 更新後設定會被覆蓋嗎？

正式更新流程會排除使用者設定、角色 profiles、授權資訊及執行紀錄。更新前仍建議保留自己的設定備份；手動覆蓋或混用不同版別不等同於正式更新流程。

## 測謊相關功能是否都能直接使用？

測謊相關處理包含自動辨識與解題，以及通知、人工回覆等流程，實際可用方式依版本及設定而異，部分流程會依賴外部服務。請先確認欲使用版本的功能及所需設定，勿推定所有處理方式均已開啟或保證成功。

## 使用自動化功能有什麼要先確認？

請先了解相關遊戲及第三方服務的使用規範、適用版本與帳號風險。星瞳的產品介紹不代表遊戲營運方允許自動化操作，也不保證任何遊戲版本持續相容或使用後不受遊戲營運方處置。

## 取消、退款或未收到授權，要聯絡誰？

請聯絡[星瞳產品客服 LINE](https://lin.ee/OC4MoWM)，並提供訂單編號（如有）、程式版本及問題說明。退款與取消條件應在付款前取得並確認；本頁尚未公告統一條件，請勿自行推定一律可退或一律不退。

請勿將付款個資、完整授權碼或帳戶憑證貼到公開 Issues。

## 如何回報辨識或流程問題？

請附上版本、選擇的遊戲、解析度、問題發生時間與已移除敏感資訊的日誌片段。不要公開授權碼、密碼、Webhook、API Key、個人設定檔或付款個資。
