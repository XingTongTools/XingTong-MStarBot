## 關於星瞳

星瞳由個人工作室維護，提供 Windows 遊戲自動化軟體的版本更新、使用說明與產品客服。

本頁為星瞳產品介紹及下載資訊，不是遊戲營運商的官方網站，也不表示取得遊戲營運商的授權或背書。適用遊戲、功能及使用限制，請在購買前確認。

## 主要功能

- **桌面介面與角色設定**：Windows 圖形介面與角色設定檔。
- **視覺辨識**：OpenCV、影像模板與模型辨識流程。
- **流程設定**：路線、巡邏、戰鬥及狀態管理，並依遊戲與地圖區分偵測資源。
- **通知整合**：Discord／Telegram 通知功能，依實際設定使用。
- **測謊相關流程**：整合自動辨識與解題，以及通知、人工回覆等處理方式；實際可用功能依版本、設定及外部服務狀態而異。
- **版本維護**：標準版（一般版）與 VM Lite 更新，以及版本化更新、備份與還原機制。

實際功能及相容性以各版本說明為準。自動化功能不代表任何遊戲或版本都持續相容，也不保證使用後不受遊戲營運方處置。

- 本產品為 Windows 桌面軟體；目前更新版需要 WebView2 Runtime。
- 標準版（一般版）與 VM Lite 的程式基底及更新包不可混用。
- 系統、硬體、遊戲版本與解析度的適用條件，請依欲使用的版本說明及客服確認。

## 下載與安裝

1. 前往[正式版本與下載頁](https://github.com/ayzn0524/MStarBot_Updates/releases)，閱讀欲安裝版本的說明。
2. **首次安裝**需取得對應版本的完整程式基底。若該 Release 只附更新包、未標示完整基底或對應版本，請先向[產品客服](https://lin.ee/OC4MoWM)確認下載來源；更新包不是完整安裝程式。
3. **既有使用者更新**前，先確認目前基底版本及版別是否符合該次更新要求，並備份自己的設定。
4. 標準版使用 `update_patch.zip`；VM Lite 使用 `update_lite_patch.zip`，並依該 Release 說明套用。

既有版本仍從 `ayzn0524/MStarBot_Updates` 檢查更新。此品牌介紹頁不搬移舊 Repository，也不變更既有程式的更新來源。
