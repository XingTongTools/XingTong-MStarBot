# 星瞳腳本

### XingTong MStarBot

支援 **楓星、新楓之谷：經典版**。以 Windows 桌面、電腦視覺與可設定流程為核心的遊戲自動化工具。

[下載最新版本](https://github.com/ayzn0524/MStarBot_Updates/releases/latest) · [查看所有版本](https://github.com/ayzn0524/MStarBot_Updates/releases)

</div>

## 主要特色

- Windows 桌面圖形介面與角色設定檔
- OpenCV、模板與模型辨識流程
- 遊戲、地圖與偵測資源分流
- 路線、巡邏、戰鬥及狀態管理
- Discord／Telegram 通知整合
- 測謊辨識與處理流程
- 一般版與 VM Lite 版本更新
- 版本化更新、備份與還原機制

## 下載與安裝

1. 前往[最新 Release](https://github.com/ayzn0524/MStarBot_Updates/releases/latest)。
2. 依版本說明選擇一般版或 VM Lite 對應檔案。
3. 首次安裝使用版本說明指定的完整程式基底。
4. 後續更新依 Release 說明套用 `update_patch.zip` 或 `update_lite_patch.zip`。

## 更新相容性

既有版本仍從 `ayzn0524/MStarBot_Updates` 檢查更新。品牌頁建立後不搬移舊 Repository，避免舊版使用者失去更新來源。
